## Features

**Write**
- Rich text: bold, italic, underline, bullet and numbered lists, text alignment
- To-do lists you can tick right from the note list
- Drawing notes for sketches and signatures, shareable as a picture
- Open links straight from a note

**Organise**
- Notebooks, pinned notes and search across every note
- Sort by last edited, date created or title
- Select several notes to pin, move or delete them at once
- Trash keeps deleted notes for 30 days

**Private**
- App lock with fingerprint, face, PIN or pattern
- Option to block screenshots
- No internet, no ads, no tracking

**Your notes, your files**
- Back up all notes to one `.numio` file and restore it any time
- Export everything as Markdown (a `.zip` of `.md` files, drawings as pictures)
- Bring notes in from Google Keep (Takeout), Samsung Notes text files, `.jex` export files, and `.md` / `.txt` files

Dark, light and palette themes that match the other Numio apps.
