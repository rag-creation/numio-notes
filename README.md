# Notes by Numio

Open-source notes app for Android, part of the Numio family.
Rich text notes, pinned notes and a dark Numio look. No internet permission:
your notes never leave your phone.

Status: early development.

## Built with
Kotlin, Jetpack Compose, Room, DataStore, Navigation and
[Compose Rich Editor](https://github.com/MohamedRejeb/compose-rich-editor) (Apache-2.0).
